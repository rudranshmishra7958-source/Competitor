# Secure Examination Platform

Monorepo for student and faculty exam portals, FastAPI backend, and a privacy-limited endpoint agent.

| Path | Purpose |
| --- | --- |
| `frontend/` | Next.js student + admin portals |
| `backend/` | FastAPI (stub until Phase 6) |
| `agent/` | Python endpoint agent (stub until Phase 9) |
| `shared/` | Domain types / event schema |

See [ROADMAP.md](ROADMAP.md) for phased scope.

```bash
cd frontend
npm install
npm run dev
```
